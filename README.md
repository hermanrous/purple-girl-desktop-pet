# 紫帽少女桌宠

一个基于 Electron 的 Windows 桌面宠物程序，角色为戴紫色渔夫帽的 Q 版元气少女。

## 功能特性

- **透明窗口**：无边框、背景完全透明，角色融入桌面
- **始终置顶**：默认置顶显示，可通过右键菜单开关
- **鼠标拖拽**：左键按住角色可自由移动位置
- **点击互动**：点击角色轮流触发 4 种互动动作
  - ⬆️ 跳一下
  - 🫧 弹一弹（压缩回弹）
  - ⬅️ 向左跳
  - ➡️ 向右跳
- **对话气泡**：互动时随机显示有趣的中文对白，不透明白底气泡位于角色上方
- **滚轮缩放**：鼠标滚轮可实时调整桌宠大小（40% - 250%）
- **右键菜单**：
  - 4 种互动动作快捷触发
  - 调整大小（迷你/小/标准/大/超大/巨大）
  - 始终置顶开关
  - 隐藏桌宠
  - 退出程序
- **系统托盘**：最小化到托盘，可快速显示/退出
- **待机动画**：呼吸微动 + 随机眨眼

## 系统要求

- Windows 10 / 11（64 位）
- 构建时需要 Node.js 18+（仅构建需要，运行时不需要）

## 构建方法

### 方式一：一键构建（推荐）

1. 确保已安装 [Node.js](https://nodejs.org/) 18 或更高版本
2. 双击运行 `build-windows.bat`
3. 等待构建完成（首次约 5-10 分钟）
4. 构建产物位于：
   ```
   release\紫帽少女桌宠-win32-x64-ready-to-run\紫帽少女桌宠.exe
   ```

### 方式二：手动构建

在项目目录下打开命令行，依次执行：

```bash
npm ci
npm run process:assets
npm run package:win
```

## 运行方法

构建完成后，进入 `release\紫帽少女桌宠-win32-x64-ready-to-run\` 目录，双击 `紫帽少女桌宠.exe` 即可运行。

> **注意**：请保留整个目录，不要只单独复制 EXE 文件。EXE 依赖同目录下的其他运行时文件。

## 使用说明

| 操作 | 效果 |
|------|------|
| 左键单击角色 | 轮流触发互动动作 + 对话气泡 |
| 左键拖拽 | 移动桌宠位置 |
| 鼠标滚轮 | 放大/缩小桌宠 |
| 右键单击 | 打开功能菜单 |
| 托盘左键 | 显示/隐藏桌宠 |

## 常见问题

**Q: 双击 EXE 后没有反应？**
A: 请确保保留了整个目录，不要只复制 EXE。首次启动可能需要几秒。

**Q: 安全软件提示未知发布者？**
A: 本程序未进行代码签名，属于正常现象。选择"仍要运行"即可。

**Q: 如何修改对话内容？**
A: 编辑 `pet-spec.json` 中 `experience.interactions[].feedback` 数组，重新构建即可。

**Q: 如何更换角色图片？**
A: 替换 `incoming-assets/` 中的对应 PNG 文件（保持透明背景），重新运行 `npm run process:assets` 和构建。
